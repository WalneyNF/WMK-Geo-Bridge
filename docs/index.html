1. Para que serve?

O WMK Geo Bridge é uma ponte independente entre sistemas GPS e plataformas geoespaciais. O Traccar recebe posições de rastreadores; o WMK Geo Intelligence exibe dados no globo 3D. A ponte padroniza os dados em JSON, permitindo que outros sistemas também os consumam. Não é necessário instalar WMK ou Traccar para testar a rota /health.

Três produtos distintos: WMK Geo Intelligence (visualização), Traccar (rastreamento), WMK Geo Bridge (integração). O Bridge não deve acessar diretamente bancos privados de terceiros.

2. Instalação no Windows

Requer Python 3.10 ou superior. Não requer pacotes externos. No PowerShell:

git clone https://github.com/WalneyNF/WMK-Geo-Bridge.git
cd WMK-Geo-Bridge
py -3 src/bridge.py

Alternativamente execute scripts/iniciar.bat. Teste http://127.0.0.1:8766/health. Resposta esperada: JSON com status ok. A porta pode ser alterada por WMK_BRIDGE_PORT. Se estiver ocupada, finalize o processo anterior ou escolha outra porta.

3. API REST explicada

GET /health: informa disponibilidade. GET /api/v1/capabilities: informa fontes e configuração sem expor segredos. GET /api/v1/vehicles: retorna veículos do Traccar quando houver credenciais. POST /api/v1/positions: aceita JSON externo apenas se WMK_BRIDGE_API_KEY estiver configurada; retorna 202 mas ainda não persiste nem retransmite a posição.

GET http://127.0.0.1:8766/api/v1/vehicles
{
 "schemaVersion": "1.0",
 "source": "traccar",
 "items": [
  {"id":"1","deviceId":1,"name":"Carro exemplo","source":"traccar",
   "simulated":null,
   "position":{"latitude":-22.28,"longitude":-42.53,
               "speedKmh":42.0,"heading":90,
               "timestamp":"2026-11-06T12:00:00Z","valid":true}}
 ],
 "count":1,
 "timestamp":"2026-11-06T12:00:01Z"
}

Este JSON é ilustrativo. Latitude e longitude usam graus decimais WGS84; speedKmh usa km/h; heading é o rumo em graus; timestamp é uma data ISO 8601. O campo simulated=null indica que a origem real/simulada não foi verificada.

4. Conectar ao Traccar

Inicie o servidor Traccar em http://127.0.0.1:8082. Gere um token válido no Traccar (ou use credenciais de uma conta autorizada). Em uma nova janela PowerShell, antes de iniciar o Bridge:

$env:WMK_TRACCAR_URL = "http://127.0.0.1:8082"
$env:WMK_TRACCAR_TOKEN = "TOKEN_VALIDO"
py -3 src/bridge.py

Como alternativa, configure WMK_TRACCAR_USER e WMK_TRACCAR_PASSWORD. O Bridge consulta /api/devices e /api/positions, associando posições pelo deviceId. Não grava no Traccar. Sem credenciais, retorna 503; em falha de conexão ou resposta inválida, retorna 502. Nunca publique tokens no repositório.

5. Consumir em outras aplicações

JavaScript, Python, PHP, C#, Visual FoxPro e outros clientes HTTP podem consultar a API. Exemplo JavaScript:

const response = await fetch('http://127.0.0.1:8766/api/v1/vehicles');
if (!response.ok) throw new Error('HTTP ' + response.status);
const data = await response.json();
for (const vehicle of data.items) {
  if (vehicle.position) console.log(vehicle.name, vehicle.position);
}

Exemplo Python em examples/cliente.py. No WMK Geo Intelligence, o próximo passo será criar uma camada Cesium independente que consuma este contrato e possa ser ligada ou desligada. Ainda não está implementada nesta versão.

6. Segurança

O serviço escuta somente em 127.0.0.1, não em todas as interfaces. Os endpoints GET não têm autenticação própria e por isso não devem ser expostos publicamente. O CORS limita origens do navegador, mas não protege clientes não navegadores. Para produção, é obrigatório implementar autenticação de leitura, autorização por usuário/dispositivo, TLS, auditoria, retenção de dados e limitação de requisições.

O endpoint POST é experimental: precisa de WMK_BRIDGE_API_KEY e cabeçalho X-WMK-API-Key. Não confunda 202 Accepted com armazenamento ou envio ao Traccar.

7. Guia do desenvolvedor

src/bridge.py contém Handler (rotas HTTP), traccar_get (cliente autenticado) e normalize (contrato comum). Para adicionar um provedor novo, crie um adaptador isolado, converta seus campos para o mesmo esquema e escreva testes antes de expor a fonte. Não introduza credenciais no frontend.

py -3 -m unittest discover -s tests -v
py -3 -m py_compile src/bridge.py

Testes devem cobrir unidades de medida, coordenadas inválidas, autenticação, erros HTTP, latência, reconexão e privacidade. A arquitetura atual é uma base de laboratório, não uma solução de alta disponibilidade.

8. O que ainda falta
